# Data

`arabic_genai_competency_data.csv` — 145 respondents. 28 Likert items across four dimensions
(prefixes AW, AP, PC, AS), seven open items (Q1 to Q7), and background variables. Item wording
and response options are in `codebook.csv`. Respondents are identified only by
`participant_id`.

`codebook.csv` — item identifiers, full wording, response format and scoring for every variable.

`gold/ar_padt-ud-test.conllu` — test split of UD Arabic-PADT, the gold standard for the
morphosyntax probe. Redistributed under CC BY-NC-SA 3.0; see `gold/PADT_LICENSE.txt` and
`gold/PADT_README.md` for terms, contributors and provenance. Genre is news; lemmas, UPOS tags,
features and relations are converted from manual annotation.
