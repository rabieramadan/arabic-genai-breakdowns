# Superseded working files

These two files are revision-history working documents, not results. They were
written during an earlier revision round and the numbers in them no longer match
the submitted manuscript.

- `corrected_statistics_paper2.csv` records an earlier recomputation pass. Its
  stance comparison, F(2, 127) = 16.77 with n = 130, has since been superseded by
  F(2, 132) = 17.76 with n = 135, which is the value in the manuscript and the
  value `code/01_survey_analysis.py` produces.
- `consistency_audit_paper2.csv` checks an earlier draft against earlier tables.
  Its barrier prevalences (76.6, 39.7, 14.2) come from a different denominator
  than the released ones (71.6, 48.2, 16.3 over the 141-respondent barrier
  corpus, in `results/barrier_theme_prevalence.csv`).

They are kept for transparency about the revision history. Do not cite numbers
from this folder. The authoritative tables are in `results/`.
